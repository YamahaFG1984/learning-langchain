把《Learning LangChain》读成能跑起来的东西

这是 O'Reilly《Learning LangChain》（Mayo Oshin & Nuno Campos 著）全书 11 章的中文精读。 每一章都从「为什么需要它」讲起，用图把机制画出来，再给一段你现在就能 python xxx.py 跑通的代码 —— 代码已经全部升级到 LangChain 1.x / LangGraph 1.x。

langchain 1.xlanggraph 1.xlangchain-openai 1.x @langchain/langgraph 1.4Python ≥ 3.10Node ≥ 20

这本书在讲什么

全书其实只回答一个问题：怎么把一个「会说话，但什么都不知道、也什么都做不了」的模型， 变成一个能查你的资料、能记住你、能替你干活、还能被信任的应用。

11 章沿着一条很清楚的线走：前 3 章解决「知识」问题，第 4 章解决「记忆」问题，5–7 章解决「行动」问题，8–10 章解决「可信」问题，第 11 章谈产品形态。左侧栏的五个部分就是按这条线分的。

开始之前：环境准备

本仓库的代码已经全部升级到 LangChain 1.x。跟着下面三步走，就能跑通绝大多数示例。

1. 环境变量

bash
# 在仓库根目录
cp .env.example .env
# 然后填入 OPENAI_API_KEY；LANGCHAIN_API_KEY 用于 LangSmith 追踪（第 9、10 章需要）

2. Python

bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e .
python ch1/py/b-chat.py

3. JavaScript

bash
npm install
node ch1/js/b-chat.js
★ 向量库：一条 Docker 命令

第 2、3 章大量示例需要一个带 pgvector 扩展的 Postgres。跑一次就够，之后所有章节共用：

bash
docker run --name pgvector-container \
  -e POSTGRES_USER=langchain -e POSTGRES_PASSWORD=langchain \
  -e POSTGRES_DB=langchain -p 6024:5432 \
  -d pgvector/pgvector:pg16

书是 0.2/0.3 写的，代码是 1.x 跑的

《Learning LangChain》成书于 2025 年初，用的是 LangChain 0.2/0.3。LangChain 1.0 做了一次不小的整理，书里一部分 import 路径已经失效。 本仓库的代码已全部修好，教程里凡是和纸质书有出入的地方，都用紫色的「1.x 变更」卡片标了出来，方便你对照原书阅读。

最主要的一条规则：langchain 主包只保留「现代」API（create_agent、init_chat_model、消息与工具）；链、检索器、索引、hub 这些历史组件整体搬到了 langchain-classic。

⚠ 还有一个要留意

langchain-community 已进入停止维护状态（import 时会打印一条 DeprecationWarning）。它仍然能用， 本书用到的加载器、DuckDuckGo 工具、PGVector 等目前也还没有全部拆出独立包，所以仓库保持原样。 真做生产项目时，优先找有没有对应的独立集成包（langchain-postgres、langchain-chroma、langchain-tavily 等）。

💡 一句话总结

如果你只记住一件事：LangChain 负责把一次模型调用的「两头」做好（拼提示、收输出）， LangGraph 负责把很多次调用编排成一个有状态、能循环、能被人接管的图。 剩下的 11 章，都是在展开这句话。
