langchain 1.x langgraph 1.x langchain-openai 1.x @langchain/langgraph 1.4 Python ≥3.10 Node ≥20

这本书在讲什么

全书其实只回答一个问题：怎么把一个「会说话但什么都不知道、也什么都做不了」的模型，变成一个能查你的资料、能记住你、能替你干活、还能被信任的应用。

11 章沿着一条很清楚的线走。前 3 章解决「知识」问题，第 4 章解决「记忆」问题，5–7 章解决「行动」问题，8–10 章解决「可信」问题，第 11 章谈产品形态。

开始之前：环境准备

本仓库的代码已经全部升级到 LangChain 1.x。跟着下面三步走就能跑通绝大多数示例。

1. 环境变量

终端
# 在仓库根目录
cp .env.example .env
# 然后填入 OPENAI_API_KEY；LANGCHAIN_API_KEY 用于 LangSmith 追踪（第 9、10 章需要）

2. Python

终端
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e .
python ch1/py/b-chat.py

3. JavaScript

终端
npm install
node ch1/js/b-chat.js

向量库：一条 Docker 命令

第 2、3 章大量示例需要一个带 pgvector 扩展的 Postgres。跑一次就够，之后所有章节共用：

docker run --name pgvector-container \
  -e POSTGRES_USER=langchain -e POSTGRES_PASSWORD=langchain \
  -e POSTGRES_DB=langchain -p 6024:5432 \
  -d pgvector/pgvector:pg16

书是 0.2/0.3 写的，代码是 1.x 跑的

《Learning LangChain》成书于 2025 年初，用的是 LangChain 0.2/0.3。LangChain 1.0 做了一次不小的整理，书里的一部分 import 路径已经失效。本仓库的代码已全部修好，教程里凡是有差异的地方都用橙色的「1.x 变更」卡片标出来，方便你对照原书阅读。

最主要的一条规则：langchain 主包只保留「现代」API（create_agent、init_chat_model、消息与工具）；链、检索器、索引、hub 这些历史组件整体搬到了 langchain-classic。

书里（0.3）现在（1.x）出现在

langchain.storage.InMemoryStorelangchain_core.stores.InMemoryStore第 2 章
langchain.retrievers.*langchain_classic.retrievers.*第 2、3 章
langchain.chains.*langchain_classic.chains.*第 3 章
langchain.utils.mathlangchain_classic.utils.math第 3 章
langchain.hublangchain_classic.hub第 9、10 章
langchain_core.pydantic_v1直接 pydantic第 1、3、8 章
MemorySaverInMemorySaver（旧名仍是别名）第 4、8 章

还有一个要留意

langchain-community 已进入停止维护状态（import 时会打印一条 DeprecationWarning）。它仍然能用，本书用到的加载器、DuckDuckGo 工具、PGVector 等目前也还没有全部拆出独立包，所以仓库保持原样。真做生产项目时，优先找有没有对应的独立集成包（langchain-postgres、langchain-chroma、langchain-tavily 等）。

怎么用这份教程

阅读方式

先看图，再看代码

每章的图都是画机制的，不是装饰。看懂图之后再读代码，你会发现代码只是把图翻译了一遍。

语言

Python / JS 一键切换

右上角的按钮会切换全站所有代码块的语言，并记住你的选择。两种语言的示例是等价的。

动手

每章都能跑

代码块上方标了对应的仓库文件路径，直接 python 路径 就能看到输出。

对照原书

橙色卡片 = 有出入

凡是和纸质书不一致的地方（API 改名、书上的 bug）都做了标注，不会让你踩坑。
